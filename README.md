# Ethera Studio
## Features Included

- Home page with header, hero section, about section, services cards, and footer
- Contact page with a validatable form
- JavaScript form validation with inline error messages
- No-page-refresh confirmation message after successful submission
- Responsive design for desktop and mobile layouts
- Reusable React components: Header, Footer, Home, Contact, ServiceCard
- useState and useEffect used in the app
- Props-based component composition

## Project Structure

- src/App.js – app routing and layout
- src/components/header.jsx – navigation header
- src/components/footer.jsx – page footer
- src/components/ServiceCard.jsx – reusable service cards
- src/pages/home.jsx – landing page content
- src/pages/contact.jsx – form page and validation logic
- src/services/formValidation.js – validator logic
- src/App.css – all responsive design styles

## Run the Project

1. Open the terminal in the project folder.
2. Install dependencies:
   npm install
3. Start the app:
   npm start
4. Open http://localhost:3000

## Build for Production

npm run build
